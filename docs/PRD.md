## 1. 项目概述

### 1.1 项目背景

当前项目是一个单页HTML应用（index.html，约3700行），用于学校考试成绩追踪和分析。由于代码结构混乱、功能扩展困难、UI体验不佳，需要进行全面重构。

### 1.2 项目目标

| 目标 | 描述 |
|------|------|
| **代码重构** | 将单文件拆分为模块化架构，提高可维护性 |
| **功能增强** | 增加管理员端、学习目标、成绩报告等新功能 |
| **体验优化** | 采用现代化UI设计，提升用户体验 |
| **数据安全** | 从本地存储迁移到服务器存储，解决数据丢失问题 |

### 1.3 目标用户

| 用户类型 | 使用场景 | 主要诉求 |
|---------|---------|---------|
| **学生** | 查询个人成绩、了解学习情况 | 快速查看成绩趋势、获取学习建议 |
| **教师** | 管理班级学生、录入成绩、分析班级情况 | 高效录入成绩、掌握班级整体情况 |
| **管理员** | 管全校数据、配置系统设置 | 统一管理、批量操作、数据分析 |

### 1.4 核心价值主张

> **让成绩管理更智能，让教学决策更有据**

**3.2.3.1 全科视图（默认显示）**

展示内容：

| 区域 | 内容 |
|------|------|
| **总分卡片** | 总分大字显示 + 满分 + 得分率 + 等级标签(A/B/C/D/E) |
| **各科成绩列表** | 科目名称 \| 原始得分 / 满分 \| 得分率 \| 排名 |
| **排名信息** | 班级排名、年级排名（如有） |
| **考试选择器** | 切换查看不同考试的成绩 |

**各科成绩行交互：**
- 点击某一行 → 自动切换到该科的"单科视图"

**3.2.3.2 单科视图（点击科目后显示）**

以"数学"为例，展示内容：

| 区域 | 内容 |
|------|------|
| **单科总分** | 该科得分 / 满分 \| 得分率 \| 排名 |
| **历次成绩趋势** | 折线图：X轴=考试日期, Y轴=分数 |
| **班级对比** | 与班级平均分的差距（高/低多少分）|
| **年级对比** | 与年级平均分的差距 |
| **难度标注** | 本次考试的难易程度 |

**3.2.3.3 多次考试对比**

在"全科视图"下，支持选择两次或多次考试进行对比：

| 功能 | 说明 |
|------|------|
| 考试选择器 | 多选框，可选择多次考试 |
| 对比表格 | 各科成绩变化、总分变化、排名变化 |
| 颜色标记 | 进步(绿色↑) / 退步(红色↓) / 持平(灰色→) |

**3.2.3.4 排名变化趋势**

展示内容：
- 折线图显示历次考试的班级排名变化
- 折线图显示历次考试的年级排名变化

**3.2.3.5 成绩分布位置**

展示内容：
- 在班级中的位置可视化（如：前10%、前25%等）

##### 3.3.4.3 📝 成绩修改（原"成绩录入"，嵌入此处）

**说明**：成绩修改功能嵌入在学生分析模块中，有两种使用场景：

**场景A：在单个学生详情页中修改**
- 点击某个学生进入详情页
- 在成绩列表中直接编辑各科分数
- 保存后立即更新

**场景B：批量表格编辑**
- 在学生列表上方选择"批量编辑成绩"
- 选择考试后，显示该班所有学生的成绩表格
- 直接在表格中编辑各科成绩
- 支持保存全部修改

**成绩字段**：
| 字段 | 类型 | 说明 |
|------|------|------|
| 科目 | readonly | 由管理员设置 |
| 得分 | editable | 实际得分（可编辑）|
| 总分 | readonly | 根据科目自动填充 |
| 名次 | editable | 班级排名（可编辑）|

> **注意**：教师不能创建新考试或设置科目分值，这些由管理员负责。

### 3.4 管理员端模块

> **📌 管理员端是什么？**
>
> 管理员端是系统的**后台管理中心**，只有学校指定的管理员可以访问。
> 它负责**基础数据配置**和**全局管理**，是整个系统运行的基础。
>
> **简单类比**：
> - 教师端 = 教室（教课、批改作业）
> - 学生端 = 课桌（看自己的成绩）
> - 管理员端 = 学校办公室（排课表、管学生档案、设考试）
>
> **管理员需要做的事情**：
> 1. 创建年级、班级（比如"高一"下面有哪些班）
> 2. 创建教师账号，分配他们管理的班级
> 3. 创建考试（比如"期中考试"、"月考1"），设置各科满分
> 4. 批量导入学生数据和成绩数据（从Excel导入）
> 5. 查看全校整体数据分析
> 6. 发布公告通知
> 7. 系统设置（修改密码策略、备份数据等）
