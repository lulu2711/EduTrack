# EduTrack 智能成绩管理与分析系统

## 项目简介

EduTrack 是一个现代化的教育成绩管理平台，专为学校、教师和学生设计。系统提供成绩查询、趋势分析、班级管理等功能，帮助教育工作者更好地了解学生学习情况，帮助学生制定学习目标。

## 功能特性

### 学生端
- 📊 **成绩查询**: 智学网风格的 Tab 切换界面，支持总分和各科成绩查看
- 📈 **趋势分析**: ECharts 图表展示成绩变化趋势、排名变化
- 🎯 **学习目标**: 设定和管理个人学习目标，追踪完成进度

### 教师端
- 📋 **班级分析**: 班级成绩统计、成绩分布图、各科平均分对比
- 👨‍🎓 **学生管理**: 学生列表、成绩详情查看、进退步分析
- 📊 **进退步分析**: 进步/退步学生 TOP10 排行榜，可视化图表

### 管理员端
- 🏫 **班级管理**: 全校班级列表、学生名单、选科组合查看
- 👨‍🏫 **教师管理**: 教师信息管理、班级分配
- 📈 **数据概览**: 全校统计数据、年级分布

## 技术架构

### 前端
- **框架**: React 18 + TypeScript
- **构建工具**: Vite
- **样式**: Tailwind CSS
- **状态管理**: Zustand
- **图表**: ECharts
- **路由**: React Router v6

### 后端
- **框架**: Express + TypeScript
- **认证**: JWT (JSON Web Token)
- **安全**: Helmet, CORS, Rate Limiting

### 数据
- **当前版本**: 本地 JSON 文件
- **数据文件**:
  - `school_data.json` - 学校班级和学生数据
  - `teachers.json` - 教师账号数据
  - `grade_subject_reports/*.json` - 144 个成绩报告文件

## 快速开始

### 环境要求
- Node.js 18+
- npm 9+

### 安装步骤

1. **克隆项目**
```bash
git clone <repository-url>
cd Edu
```

2. **安装后端依赖**
```bash
cd server
npm install
```

3. **安装前端依赖**
```bash
cd ../client
npm install
```

4. **启动开发服务器**

后端（端口 3000）：
```bash
cd server
npm run dev
```

前端（端口 5173）：
```bash
cd client
npm run dev
```

5. **访问应用**
- 首页: http://localhost:5173
- 后端 API: http://localhost:3000
